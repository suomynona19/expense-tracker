# Пет-проект: Персональный учёт расходов и доходов (Python Backend)

## Уровень 1: Базовая версия ("на коленке")
**Цель**: Рабочий прототип с минимальным функционалом

### Функционал:
1. **Telegram Bot (асинхронный)**:
   - `/start` - приветствие и краткая инструкция
   - `/add_income [сумма] [категория]` - добавление дохода
   - `/add_expense [сумма] [категория]` - добавление расхода
   - `/balance` - вывод текущего баланса
   - `/report [период]` - отчёт за день/неделю/месяц

2. **Хранение данных**:
   - SQLite + SQLAlchemy Core (без ORM)
   - Таблицы: `transactions`, `categories`
   - Простейшие запросы без сложных JOIN

3. **Логика**:
   - Подсчёт баланса (доходы - расходы)
   - Группировка по категориям в отчёте

### Ожидаемый результат:
- Бот реагирует на команды
- Данные сохраняются между перезапусками
- Консольный лог операций

---

## Уровень 2: Docker + PostgreSQL
**Цель**: Перенос в контейнеры и "взрослую" СУБД

### Добавляем:
1. **Docker**:
   - Два сервиса в `docker-compose.yml`: `app` (Python) и `db` (PostgreSQL)
   - Переменные окружения для подключения к БД

2. **PostgreSQL**:
   - Миграция схемы из SQLite
   - Настройка пула соединений

3. **Улучшения**:
   - Валидация вводимых данных
   - Обработка ошибок БД
   - Логирование в файл

### Ожидаемый результат:
- Запуск проекта одной командой `docker-compose up`
- Данные сохраняются в volume PostgreSQL
- Конфигурация через .env

---

## Уровень 3: Асинхронность и Redis
**Цель**: Оптимизация производительности

### Добавляем:
1. **Асинхронность**:
   - Переход на `asyncpg` или SQLAlchemy 2.0+ async
   - Асинхронные хендлеры для бота

2. **Redis**:
   - Кэширование частых запросов (например, баланс)
   - Временное хранение отчётов
   - Rate-limiting для бота

3. **Улучшения**:
   - Фоновые задачи (например, ежемесячные отчёты)
   - Healthcheck для docker-compose

### Ожидаемый результат:
- Уменьшение времени отклика бота
- Статистика использования кэша
- Асинхронные логгеры

## Уровень 4: Миграции и продвинутые фичи
**Цель**: Профессиональный workflow

### Добавляем:
1. **Alembic**:
   - Автогенерация миграций
   - Откат изменений
   - Тестовые данные в seed-миграциях

2. **Доп. функционал**:
   - Мультивалютность
   - Кастомные периоды для отчётов
   - Экспорт в CSV/Excel

3. **Тестирование**:
   - Pytest + async tests
   - Тестовый контейнер с БД
   - CI/CD пайплайн (GitHub Actions)

### Ожидаемый результат:
- История изменений схемы БД
- Возможность деплоя на продакшен-сервер
- 80%+ coverage тестами
